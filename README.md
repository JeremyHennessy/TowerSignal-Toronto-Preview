# TowerSignal Toronto Preview

Isolated public preview for the Toronto market build. Production TowerSignal and its `main` branch are not modified by this repository.

The deployed application is built from `JeremyHennessy/TowerSignal@agent/toronto-market-20260828` with Toronto feature flags enabled.

Toronto data remains subject to the limitations shown in the application, including an unknown total cooling-tower denominator, blocked AIC supporting-document transport, permission-required Construction Act sources, and unresolved municipal identities.
